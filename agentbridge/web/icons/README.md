# Sally PWA icon v2

Sally uses the orange minimalist portrait from the owner's selected panel 4.
Rick's existing artwork is unchanged. Square, opaque PNGs let the phone apply its
own icon shape. Sizes: 192 and 512 for the manifest, 180 for Apple touch, 1024 master.
The artwork was reconstructed with the built-in imagegen tool, then resized with
Pillow. It is a close reconstruction, not a pixel-identical enlargement.

Generation prompt: reconstruct only Sally in panel 4 (bottom-left panel, left
tile) of the supplied comparison board; preserve the orange-red updo, peach
skin, dark teal open eye, wink, happy open-mouth smile, black scoop-neck shirt,
thick dark outlines and orange gradient. Head and shoulders only; no hands,
gestures, text, border, rounded corners or 3D. Extend the background to a square.

Versioned URLs avoid reuse of the previous install/notification artwork. Existing
home-screen installations may need to be removed and added again to refresh the
OS-managed icon; a page reload does not guarantee that refresh.
