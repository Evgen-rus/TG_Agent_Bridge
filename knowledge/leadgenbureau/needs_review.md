# Needs review

Короткий список пунктов, которые могут менять работу агента, но сейчас
не подтверждены как жёсткий стандарт.

1. Правило доставки «сегодня данные за вчера» — действует ли во всех текущих проектах.
2. Полный актуальный набор функций личного кабинета: не смешивать старые версии UI.
3. Текущая роль и состав данных Пикселя.
4. С какого объёма обработки делать полноценную аналитику; старые пороги могут быть неактуальны.
5. Какие из эмпирических рекомендаций по времени звонка, мобильным номерам и 75–80% дозвона
   считать обязательной методикой, а какие — ориентиром.
