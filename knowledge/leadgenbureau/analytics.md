# Аналитика

Audience: shared. Цифры ниже — ориентиры практики, не обещание клиенту.

## Как оценивать качество

«База плохая» — не вывод. Цепочка:

объём → сколько реально обработано → дозвон → качество первого входа →
статусы → комментарии → лиды и другие сигналы спроса → конкуренты →
источники → решение.

Минимум смотреть: передано, обработано, % обработанности, % дозвона,
попытки, лиды, отложенный спрос, уже купили, работают с другими, нецелевые,
жёсткие отказы, необработанные, недозвоны, автоответчики, сбросы,
комментарии, срезы по конкурентам и источникам.

## Два фактора

Источник: конкуренты, свежесть, география, состав обращений, канал.
Обработка: скорость первого звонка, попытки, дозвон, первая фраза,
квалификация, статусы, комментарии, повтор, работа с отложенным спросом.

Не списывать результат только на одну сторону.

## Сегментация

Слабый проект не выключать целиком.

Проект → конкурент → источник/канал → обработка → результат.

Смотреть, кто дал лиды, где отложили, где уже купили, где много нецелевых,
где проблема в недозвоне, какой источник конвертит лучше.
Потом: оставить сильного, отключить слабого, расширить канал, пересобрать
номера, изменить обработку, повторить дозвон.

## Сигналы спроса

Не сводить к «лид / не лид». Полезны: прямой лид, отложенный интерес,
уже купили, актуально но работают с другим, интерес был но перенесли.
Не каждый отказ — сигнал спроса.

Ориентир прямой конверсии в лиды: около 3–5% из идентификаций может быть
хорошим рабочим результатом. По 10–20 звонкам окончательные выводы рано.
Полноценную аналитику делать после накопления заметного объёма, а не
по слишком маленькой выборке.

## Типовые жалобы

«Никто не берёт трубку» — сначала дозвон: попытки, интервалы, время,
исходящий номер, мобильный/городской, другой оператор, автоответчики,
сбросы, итоговый %.

«Прозвонили, результата нет» — один набор не считается циклом. Проверить
волну, статусы, комментарии, отложенный спрос.

«Люди не понимают, откуда звоним» — выборочно 2–3 разговора: первая фраза,
не презентация ли сразу, проверяют ли актуальность, не спорят ли об источнике,
не называют ли конкурента.

«Там одни нецелевые» — считать процент, причины, конкурента, источник,
есть ли лиды и отложенный спрос среди остальных. Не склеивать все отказы
в нецелевые.

## РОП

Переводить впечатления в данные. Пример нормальной оценки:
из 100 обработано 82, дозвон 76%, 4 лида, 9 отложенных, 6 уже купили,
11 нецелевых; конкурент А дал 3 лида, Б слабый, В много недозвонов.
После этого уже решение.
