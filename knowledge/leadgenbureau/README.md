# База знаний ЛидгенБюро

Общие знания компании для AgentBridge. Это не wiki отдельного Telegram-чата.

**ЛидгенБюро и LeadRecord — сейчас одно и то же.** Основное имя: **ЛидгенБюро**.
`LeadRecord` может встречаться в домене, коде и старых названиях.

## Слои

- `core.md` — короткий слой, который AgentBridge подмешивает в каждый ход чата с пакетом `leadgenbureau`.
- `product.md`, `operations.md`, `analytics.md`, `playbooks.md`, `glossary.md` — shared: можно опираться при ответе клиенту, не раскрывая внутреннюю кухню.
- `cases.md`, `needs_review.md` — internal: для reasoning. Не называть другому клиенту чужие компании, цифры и подробности.
- Wiki конкретного чата — кто клиент, участники, его правила. Она важнее общей методики, если они расходятся.

## Как это использует AgentBridge

1. В `config.yaml` чата поле `knowledge_pack: leadgenbureau` (это значение по умолчанию).
2. Чтобы отключить пакет: `knowledge_pack: none`.
3. В prompt всегда уходит только `core.md` и список остальных файлов.
4. Узкий документ агент читает из `knowledge/leadgenbureau/` только если он нужен для текущего хода.

Общую базу меняют вручную в этих файлах. Случайное сообщение клиента её не переписывает.
