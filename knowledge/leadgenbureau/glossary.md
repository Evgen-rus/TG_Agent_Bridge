# Словарь

- **ЛидгенБюро / LeadRecord / Полит Рекорд / Полит Генбюро** — один продукт. Основное имя: ЛидгенБюро.
- **Идентификация** — контакт по телефонному взаимодействию с номерами согласованных конкурентов. Не готовый лид.
- **Конкурент-донор** — согласованный конкурент, с чьих/на чьи номера собирается сигнал.
- **Дозвон** — удалось поговорить с человеком, не просто набрать номер.
- **Недозвон** — поговорить не удалось; обработка обычно продолжается.
- **Лид** — подтверждённый интерес, есть смысл вести дальше.
- **Сигнал спроса** — подтверждение, что потребность существовала или существует: лид, отложили, уже купили, работают с другим и т.п.
- **Обработанность** — доля контактов с понятным результатом после цикла попыток, не «один набор».
- **Квалифицированный лид** — заявка, прошедшая согласованные критерии квалификации клиента (обычно до трёх KPI). Не равна идентификации.
- **Конкурент-донор / источник** — конкурент, с чьих номеров собирается сигнал; внутри донора результат может различаться по конкретным номерам.
- **Формат работы** — данные; данные с прозвоном; квалифицированные лиды под ключ. Определяет, кто прозванивает и кто отвечает за квалификацию.
- **Shared** — можно опираться в черновике ответа клиенту.
- **Internal** — только для внутреннего разбора, не пересказывать другому клиенту.
