# Операции: обработка идентификаций

Audience: shared.

## Цикл дозвона

Идентификация не обработана после одного звонка.

Первые три дня:
- минимум 3 попытки в день;
- между обычными попытками не меньше 2 часов;
- если линия занята — можно примерно через 10 минут.

Эмпирика, не закон:
- окна 11:00–13:00 и 18:00–21:00 часто лучше;
- мобильный исходящий обычно лучше городского;
- при недозвоне сменить номер и при необходимости оператора.

Если первые дни пустые: примерно с 5-го дня ещё одна волна.
Иногда полезно коротко остановить новый сбор, чтобы доработать недозвоны.

## Недозвон

Недозвон ≠ нет интереса и ≠ плохой источник.
Разделять: не взял трубку, занято, автоответчик, сброс, молчание,
техническая проблема, номер недоступен.

Рабочий ориентир итогового дозвона: около 75–80% после полного цикла.
При 40–50% рано делать вывод о всей базе. Не обещать любой проект довести
до 75–80%.

## Смысловые статусы

У клиента набор статусов в CRM может быть другим. Ниже — универсальные смыслы,
а не обязательная схема CRM.

- **Лид** — интерес подтверждён, тему можно вести дальше.
- **Попросили перезвонить** — интерес не снят.
- **Недозвон** — поговорить не удалось, обработка продолжается.
- **Автоответчик / помощник**
- **Сброс / молчит**
- **Уже купили / уже клиент** — потребность была; это сигнал спроса, не мусор.
- **Было актуально, передумали**
- **Было актуально, отложили**
- **Актуально, но работают с другими**
- **Конкурент / поставщик** — нецелевой для продажи, полезен для аналитики.
- **Не удалось связаться после полного цикла** — отдельно от промежуточного недозвона.
- **Нецелевой**
- **Не интересно** — отказ без подробностей.
- **Абонент не существует**

Не склеивать всё в один «Отказ».
«Не звоните больше» ≠ «сейчас неактуально» ≠ «уже купили» ≠ «вернитесь позже».

## Комментарии

Комментарий нужен ради следующего шага.

Примеры: интерес есть, вернуться через неделю; уже купили, рассмотреть
при следующей закупке; не наш регион; нет бюджета, через месяц;
3 попытки, не берёт трубку; линия занята, перезвонить; автоответчик,
попробовать другой номер.

## Обратная связь

ЛидгенБюро — не только поставка файла. Клиент возвращает статусы, комментарии,
лиды, недозвоны. По цифрам появляются гипотезы: оставить/отключить конкурента,
пересобрать номера, усилить дозвон, поправить скрипт.

После передачи данных команда может участвовать в управлении конкурентами,
анализе, рекомендациях по обработке и при необходимости обучении клиента.
