## Типографика

Системный шрифт Android по умолчанию: `Inter` при наличии, fallback `system-ui, -apple-system, Roboto, sans-serif`. Не вшивать чужие проприетарные шрифты. Русский: проверить цифры, длинные названия сделок, падежи, знаки кавычек.

- Display: 26–28px / 1.2, semi-bold, только в кратком hero.
- H1: 22–24px / 1.25, semi-bold.
- H2: 16–18px / 1.35, semi-bold.
- Body: 14–15px / 1.5, regular.
- Caption: 11–12px / 1.4, medium.
- Primary button: 14px / 1.2, semi-bold.

## Spacing and sizing

`2 / 4 / 8 / 12 / 16 / 20 / 24 / 32` px. Горизонтальный gutter 16–20px. Gap карточек 10–12px. Высота tap targets >=44px. Акцентный CTA 48–52px. На экране смартфона показывать максимум 1 главный CTA и 2 вторичных действия на карточку. Не делать больше 4 основных пунктов навигации.

## Layout

- Основная ширина: 360–430px; базовый визуальный макет 390×844px.
- Верхняя системная safe area: учитывать cutout/notch; контент не должен уходить под статус-бар.
- На >=768px: центрированная мобильная колонка + необязательная боковая панель при разработке, но не превращать интерфейс в десктопную CRM без необходимости.
- Нижняя навигация фиксирована и не накрывает последнюю карточку.
- Поле ввода фиксируется над клавиатурой, с учётом Android visualViewport/resize поведения после тестирования на реальном устройстве.

## Motion

150–220мс для изменения состояния, 220–300мс для открытия детали. `prefers-reduced-motion` обязателен. В статусах выполнения использовать сдержанную анимацию, не «набирает текст» как имитацию отсутствующего прогресса.

## Состояния, критичные для MVP

`loading`, `empty`, `ready`, `error`, `offline`, `stale-data`, `pending-confirmation`, `processing`, `needs-context`, `access-denied`, `codex-limit`, `source-unavailable`.

Событие «успешно отправлено клиенту» показывать **только при наличии подтверждённого внешнего отправления**. «Скопировано в буфер» не означает «отправлено». Не показывать заведомо несуществующие статусы.

## Accessibility

Контраст основного текста ориентир WCAG AA (4.5:1 для обычного). Не полагаться на цвет для статусов. Фокус с клавиатуры видимый, aria-label для иконок. Чат читается скринридером; обновления ответов не должны бесконечно переозвучиваться. Проверить 200% увеличение текста на Android.

## Иконки и изображения

Пиктограммы минимальные (Lucide или свои SVG), толщина ~1.8–2px, единый оптический размер. Референсы внешних брендов не копировать целиком. Разработать два отдельных оригинальных app icon SVG/PNG без сторонних лого.
