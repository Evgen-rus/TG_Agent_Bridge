# 06. Этапы, критерии приёмки

## Этап D — согласование дизайна

- [ ] Четыре концепции: Rick A, Rick B, Sally A, Sally B.
- [ ] У каждой не меньше 4 связанных экранов, минимум один рабочий сценарий.
- [ ] Preview реально открывается на Android и на ПК; все интерактивные элементы понятны.
- [ ] Реалистичные **обезличенные вымышленные** данные. Дизайн не выдаёт future-функцию за готовую.
- [ ] Проверены ширины 360/390/430px, масштаб текста, Android клавиатура, safe areas.
- [ ] Выбран итоговый набор стилей и составлен список изменений.
- [ ] На этом этапе production Rick и Sally не затронуты.

## Этап M — функциональный MVP

- [ ] Два отдельных installable PWA с разными manifest/id/icons/scope/start_url.
- [ ] Реальная серверная авторизация; нет публичной регистрации.
- [ ] Евгений видит оба; Дмитрий только Rick; Сергей только Sally.
- [ ] Изоляция в том числе внутри чатов/тем, direct URL manipulation не обходит проверку.
- [ ] Rick читает доступные эпизоды и отвечает через штатную owner-логику.
- [ ] Sally читает свои доступные темы, хранит корректную историю, отвечает в контексте той же темы.
- [ ] Подтверждения действий и фактов только через существующие workflow; дублированный клик безопасен.
- [ ] Не теряются сообщения на перезапуске, не создаются лишние Codex-треды, не запускаются два конкурирующих Telegram polling-процесса.
- [ ] UI адекватен для нет сети, timeout, Codex limit, 401, 403, 404, 409, 500.
- [ ] Реальные голосовые/вложения включать только после end-to-end проверки и без обхода правил существующего pipeline.

## Этап P — безопасный запуск на VPS

- [ ] Зафиксирована исходная ревизия commit + проверенная резервная копия данных.
- [ ] Git commit + push, затем на VPS pull разрешённой ревизии.
- [ ] HTTPS, сессии, secure headers, health endpoints только при нужных правах.
- [ ] Перезапущены только затронутые сервисы, без вмешательства в другие проекты.
- [ ] Проходят unit/integration/e2e/security проверки, DB integrity.
- [ ] Рик и Салли по Telegram работают как прежде (проверены реальные сценарии по согласованным учёткам; без отправки в клиентские чаты).
- [ ] PWA устанавливаются на два телефона, иконки и изоляция различаются.
- [ ] Выданы реальные URL, инструкции входа и установки, commit hash, журнал результатов тестирования без PII.

## Если тесты не прошли

Не заявлять успех. Зафиксировать конкретную ошибку, отменить только новые изменения без удаления истории сообщений. Если deploy остановлен из-за недостающих доступов/домена — подготовить все безопасно исполнимые части и задать 1–2 конкретных вопроса.
